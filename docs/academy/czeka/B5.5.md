# B5.5 Kokpit organizatora (V13)

## Migracje do zastosowania

Brak. Kokpit czyta istniejące tabele; brak kolejki albo puli pytań pokazuje jako „niedostępne”.

## Czeka na właściciela

- G53: przegląd pełnej osi jednej edycji po zastosowaniu migracji z B0, B2 i B3.

## Ustalenia

- „Twój czas na edycję” z makiety V13 nie jest liczony, bo system nie mierzy czasu pracy organizatora. Liczbę operacji pokazuje ekran zamknięcia edycji.
- Doręczalność: plan zakłada ją tylko przy odczycie odbić, którego nie ma.
- „Prowadzący nie dostarczył slajdów” nie jest wykrywane: model nie zna terminu dostarczenia materiałów przez prowadzącego.
