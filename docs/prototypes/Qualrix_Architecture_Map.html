Warstwa 4: Model Danych (PostgreSQL / Supabase)
14 głównych tabel, RLS, triggery automatyzacji
14 tabel
▼

profiles

Rozszerzenie auth.users. Role: consultant, delivery_lead, account_manager, csm, admin. i18n preference.

consultants

Profil rozszerzony: specjalizacja, technologie[], certyfikaty[], stawka, loyalty_points, health_score, status.

contracts

Kontrakty: klient, projekt, daty, stawka/h, tryb pracy, status (active/ending/ended), przedłużenia.

contract_health_scores

4 komponenty: client_feedback (40%), stability (30%), engagement (20%), red_flags (10%). Score 0-10.

projects

Marketplace: tytuł, klient, tech_required[], seniority, rate range, work_mode, status, visibility (exclusive).

project_applications

Zgłoszenia: matching_score, status (interested → in_review → accepted/rejected). UNIQUE per project+consultant.

loyalty_transactions

Punkty: activity_type (monthly, extension, referral, certification, anniversary). Auto-trigger loyalty_status.

referrals

Polecenia: dane polecaego, status (submitted → hired → on_project), bonus points + PLN.

documents

Typy: contract, amendment, invoice, certificate, other. Supabase Storage URLs.

invoices

Faktury: numer, kwota PLN, issue/due dates, payment_status (pending → processing → paid).

skill_gap_alerts

Alerty luk kompetencyjnych: skill_name, recommendation, course_url, is_read.

pulse_surveys

Ankiety: satisfaction/engagement/recommendation (1-5), komentarz. Dla CSM.

right_to_hire_cases

Internalizacja: sygnały, kalkulator opłaty, status (detected → negotiating → settled/lost).

notifications

Powiadomienia bilingual (PL/EN): type, title, body, is_read, action_url.

⚡ Triggery automatyzacji

Rejestracja user → Auto-tworzenie profiles (role=consultant)
Nowa loyalty_transaction → Auto-update loyalty_status (Bronze→Silver→Gold→Platinum)
UPDATE na tabeli → Auto-update updated_at timestamp

Warstwa 6: Bezpieczeństwo & Autoryzacja
RLS, RBAC, GDPR, Audit Trail
5 mechanizmów
▼
Row Level Security (RLS)
Każda tabela ma polityki RLS. Konsultant widzi TYLKO swoje dane. Admin widzi wszystko. Delivery Lead widzi swój zespół.
RBAC (Role-Based Access Control)
5 ról: consultant, delivery_lead, account_manager, csm, admin. Uprawnienia na poziomie bazy (RLS) + UI (conditional rendering).
Autentykacja wielopoziomowa
Supabase Auth: Email/Password + Magic Links + SSO (Google, Microsoft). 2FA w przyszłości. JWT tokens.
GDPR / RODO Compliance
Audit trail (logowanie dostępu), encryption at rest/transit, prawo do usunięcia, eksport danych osobowych.
Supabase Storage Security
Bucket policies per rola. Dokumenty prywatne per konsultant. Signed URLs z limitem czasu. Upload size limits.
